Both references are generated from the code and checked in CI, so they cannot drift from it.

- [Command line](/tesserarr/reference/cli/): every `tesserarr` command of `artisan`.
- [API reference](/tesserarr/reference/api/): the token API under `/api/v1`, with the permission each operation needs. Signed-in users
  also find it in the web interface at `/docs/api`, where requests can be tried with their own API token.
