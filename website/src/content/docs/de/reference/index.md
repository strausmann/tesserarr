---
title: Referenz
description: Die Befehlszeile und die Token-API, erzeugt aus dem Code.
---

Beide Referenzen werden aus dem Code erzeugt und in der CI geprüft; sie können also nicht von ihm abweichen.

- [Befehlszeile](/tesserarr/de/reference/cli/): jeder `tesserarr`-Befehl von `artisan`.
- [API-Referenz](/tesserarr/de/reference/api/): die Token-API unter `/api/v1`, mit dem Recht, das jede Operation braucht. Angemeldete Nutzer
  finden sie auch in der Weboberfläche unter `/docs/api` und können dort Anfragen mit ihrem eigenen API-Token
  ausprobieren.
