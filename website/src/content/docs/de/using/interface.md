## Navigation

Ab 1024 Pixeln Breite steht die Navigation als feste Leiste links. Auf schmaleren Bildschirmen, etwa auf dem Handy, zeigt
eine Leiste oben den Menüknopf, das Logo und den Titel der Seite. Der Menüknopf öffnet die ganze Navigation als
Schublade; unten darin stehen dein Konto, Abmelden und die laufende Version. Escape, ein Tipp neben die Schublade oder
ein Link darin schließt sie wieder. Die Version öffnet **Über Tesserarr**, und nach einer Aktualisierung bietet die Navigation
Neuladen an (siehe [Version und Aktualisierungen](/tesserarr/de/using/updates/)).

Ein Freund sieht den Katalog, seine Token und sein Konto. Der Betreiber sieht zusätzlich Status, Medien, Betrieb und
Verwaltung.

## Sprache

Die Oberfläche gibt es auf Deutsch und Englisch. Ohne eigene Wahl folgt sie der Sprache deines Browsers; jede andere
Sprache ergibt Englisch. Um die Sprache für jedes Gerät festzulegen, auf dem du dich anmeldest, öffne
**Einstellungen → Darstellung → Sprache**. „Wie der Browser“ gibt die Wahl an den Browser zurück.

## Zugeklappte Abschnitte

Manche Abschnitte klappen mit einem Klick auf ihre Überschrift zu. Tesserarr merkt sich das auf dem Server, deshalb
bleibt der Abschnitt auch auf deinen anderen Geräten zugeklappt.

## Leere Ansichten

Eine Ansicht ohne Daten sagt in einem Satz, was fehlt, und bietet, wo du es ändern kannst, die passende Aktion an.

## Auf dem Handy

Felder bringen die passende Tastatur mit: ein Adressfeld die E-Mail-Tastatur, ein Codefeld den Ziffernblock. Die
Eingabetaste springt zum nächsten Feld und sendet das Formular vom letzten aus ab. Bei offener Tastatur bleiben das Feld,
seine Liste und die Hauptknöpfe eines Dialogs im Blick. Ein Kreuz in einem Such- oder Namensfeld leert es.
