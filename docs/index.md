# Tesserarr

Tesserarr shares parts of your media library with a friend over an existing
Syncthing link, so their own Sonarr or Radarr can pick up what you offered as
if it came from any other source. It is for homelab operators who already run
the \*arr stack and want to help a friend without torrents, without a public
index, and without moving files by hand. You decide who sees which library,
how much they may request, and how long an unclaimed file stays around.

!!! warning "Early development"

    Tesserarr is not usable yet. The [architecture decisions](https://github.com/strausmann/tesserarr/tree/main/docs/adr)
    are on GitHub if you want to know why things are built the way they are.
